# 铸语 PromptForge · 操作手册

本手册面向两类读者：**部署管理员**（第 1-9 章）和**普通用户**（直接跳到第 7 章看使用即可）。

---

## 1. 如何注册 DeepSeek 账号

1. 打开 DeepSeek 开放平台：**https://platform.deepseek.com** ；
2. 点击右上角「注册」，支持手机号验证码注册，或使用微信扫码登录；
3. 登录成功后进入控制台首页。

> 注意：DeepSeek 开放平台（platform.deepseek.com）是给开发者调 API 用的，与聊天网页版（chat.deepseek.com）账号相互独立，本工具使用的是**开放平台**的账号与 API。

## 2. 如何购买 API（充值）

1. 登录后进入左侧菜单「充值 / Top up」；
2. 支持支付宝、微信扫码支付，最低充值额度以页面提示为准（通常 10 元起）；
3. 充值成功后余额会实时显示在页面右上角。

费用参考（以官网实时价格为准）：`deepseek-chat` 按输入/输出 token 计费，个人轻度使用每月通常只需几元。

## 3. 如何创建 API Key

1. 进入左侧菜单「API Keys」；
2. 点击「创建 API Key」，随意命名（例如 `promptforge`）；
3. 系统会显示一串 `sk-` 开头的密钥——**这是唯一一次完整展示**，请立即复制；
4. 密钥请妥善保管：泄露后任何拿到它的人都能消耗你的余额。若怀疑泄露，删除该 Key 重新创建即可。

## 4. 如何填写 Base URL

在本工具「管理后台 → 模型配置」中填写：

```
https://api.deepseek.com
```

- 结尾**不要**带 `/`，也**不要**带 `/chat/completions`，后端会自动拼接接口路径；
- 如果你的服务器部署在海外且直连不畅，可使用官方备用地址 `https://api.deepseek.com/v1`（本工具两种写法均兼容）。

## 5. 如何填写模型名

| 模型名 | 适用场景 |
| --- | --- |
| `deepseek-chat` | 通用对话与文本生成（默认推荐，本工具两个模块都用它） |
| `deepseek-reasoner` | 深度推理（更慢更贵，一般不需要） |

本工具默认已填 `deepseek-chat`，通常无需修改。

## 6. 如何在后台测试连接

1. 用管理员账号登录本工具（初始账号来自 `.env` 中的 `ADMIN_USERNAME` / `ADMIN_PASSWORD`）；
2. 左侧菜单 →「模型配置」；
3. 填写 Base URL、模型名、API Key；
4. 点击「测试连接」：后端会真实调用一次模型（发送 `ping`），返回耗时与结果；
5. 看到「连接成功」后，打开「启用」开关，点击「保存配置」；
6. 保存后 API Key 以 AES-256 加密入库，页面只显示末 4 位掩码。

## 7. 两个模块的使用说明（普通用户）

**提示词生成**
1. 登录后进入「提示词生成」；
2. 左侧输入一句需求（如"帮我写一个周报生成提示词"）；
3. 点击生成，右侧流式输出，可直接复制；
4. 结果自动保存到「对话历史」。

**需求助手**
1. 进入「需求助手」→ 第一步填写标题和原始需求；
2. AI 会生成最多 5 个澄清问题，逐条回答（可跳过）；
3. 提交回答后点击「生成需求文档」，Markdown 文档流式生成；
4. 文档按版本保存，可在版本下拉框中切换回看。

**对话历史**
- 两个模块的记录统一在「对话历史」查看，支持按模块筛选和版本切换。

## 8. 常见错误排查

| 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| 测试连接返回 **HTTP 401** | API Key 错误、被删除，或复制时带了空格 | 重新复制 Key 粘贴；确认 Key 未在平台删除 |
| 提示 **余额不足 / Insufficient Balance** | 账户欠费 | 到 platform.deepseek.com 充值 |
| **请求超时 / 连接模型服务失败** | 网络不通、代理拦截，或 Base URL 写错 | 检查服务器能否访问 `api.deepseek.com`；核对 Base URL |
| **模型名错误 / Model Not Exist** | 模型名拼写错误 | 改回 `deepseek-chat` |
| 页面提示「管理员尚未启用任何模型配置」 | 后台没保存或没打开「启用」开关 | 进后台完成第 6 章步骤 |
| 提示「请求过于频繁」 | 触发限流（默认每用户 10 次/分钟） | 稍等一分钟再试 |

## 9. 如何更换 API Key

1. 若旧 Key 泄露：先到 DeepSeek 平台删除旧 Key 并创建新 Key；
2. 进入本工具「模型配置」→ 在 API Key 栏输入新 Key；
3. 点击「测试连接」确认成功 →「保存配置」；
4. 无需重启服务，下一次生成即使用新 Key。

## 10. 如何更换 ENCRYPT_KEY（谨慎）

`ENCRYPT_KEY` 用于加密数据库中的 API Key。**更换后已保存的 Key 将无法解密**，需按第 9 章重新填写 Key。操作顺序：

1. 修改 `.env` 中的 `ENCRYPT_KEY`（`openssl rand -hex 32` 生成）；
2. `docker compose up -d` 重建后端；
3. 重新在后台填写 API Key。

## 11. 本地部署 Ollama 作为替代（可选）

本工具当前版本仅内置 DeepSeek 适配器，但适配层（`LlmProvider`）已预留扩展位。若希望完全离线使用，可以自行部署 Ollama 并新增一个实现类：

1. 在服务器安装 Ollama：https://ollama.com ；
2. 拉取模型：`ollama pull qwen2.5:7b`（任意 OpenAI 兼容模型）；
3. Ollama 原生提供 OpenAI 兼容接口（默认 `http://localhost:11434/v1`）；
4. 在后端新增 `OllamaProvider implements LlmProvider`（可参考 `DeepSeekProvider`，协议相同，仅需去掉鉴权头），注册后管理后台即可切换 provider。

> 该章节仅为路线说明，当前代码未内置 Ollama 实现。
